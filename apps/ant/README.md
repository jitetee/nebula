# ant – Terminal‑Coding Agent


**ant** is a modular, text‑centric toolkit for Termux/Node.js that bundles dozens of ready‑to‑use utilities (array, string, math, date, crypto, HTTP, file, CLI, validation) **plus** new CLI helpers supporting rounded box framing, banner rewrite, (pin) input footer, and updated error handling (no crash on unknown tool).


---


## Quick Start


```bash
# 1️⃣ Clone the repository
git clone https://github.com/kashsight/ant.git
cd ant


# 2️⃣ Install Node dependencies (Node 18+ recommended)
npm i


# 3️⃣ Run the demo that creates a Word report with a chart
demo.js
```
